## 🔥 Fix These 4 Things First (High Impact, Easy Fixes)

### 1. Remove Old "Rafter M" Gift Card (5 min)
**Problem:** Gift card still shows "RAFTER M HAT COMPANY" logo  
**Impact:** Confuses customers, damages rebrand  
**Fix:**
- Go to: Shopify admin → Products → "Moon Ridge Gift Card"
- Either: Upload new gift card image with Moon Ridge branding
- Or: Unpublish gift card from Shop channel temporarily

---

### 2. Upload 3 Missing Collection Images (20 min)
**Problem:** Collections show blank gray tiles (looks broken)  
**Impact:** Kills click-through, looks unprofessional  
**Fix:**
- Go to: Shopify admin → Products → Collections
- Update these 3 collections:
  - **Best Sellers** - Add hero image (suggest: lineup of top 3 hats)
  - **Best Selling Stetson's** - Add hero image (classic Stetson shot)
  - **New Arrivals Hats** - Add hero image (newest products)
- Image specs: 1200x800px minimum, lifestyle or product hero shots
- Note: "Western Hats" already has image ✅

---

### 3. Replace Blurry Hero Image (10 min)
**Problem:** Current cover photo is out-of-focus, low impact  
**Impact:** Weak first impression for browsers  
**Fix:**
- Go to: Sales channels → Shop → Customize → Store profile → Cover image
- Upload sharp, high-res image options:
  - Lineup of signature Stetson/Resistol hats
  - Lifestyle shot: customer wearing hat (western/heritage vibe)
  - Store interior with hat displays
- Requirements: 1500x500px minimum, sharp focus, on-brand

---

### 4. Add Store Description (5 min)
**Problem:** No "About" section visible  
**Impact:** Misses trust-building, search relevance  
**Fix:**
- Go to: Sales channels → Shop → Store details → About
- Write 2-3 sentences, for example:

> "Fayetteville, Arkansas's destination for premium western hats since [YEAR]. We specialize in Stetson, Resistol, and Pendleton hats with expert hat shaping and fitting services. From classic cowboys to modern fashion styles, we help you find your perfect hat."

## 📅 Do Next Week (Medium Impact)

### 5. Set Free Shipping Messaging (10 min)
- Go to: Sales channels → Shop → Offers
- Add offer: "Free Shipping on orders over $[X]"
- Suggestion: Set at $75 or $100 threshold

### 6. Enable Delivery Estimates (5 min)
- Go to: Settings → Shipping & Delivery
- Ensure delivery estimates are turned on
- Shop will show "Estimated delivery: [date]" automatically

### 7. Create Shop Cash Offer (15 min)
- Go to: Sales channels → Shop → Offers → Create offer
- Suggestion: "Earn 5% Shop Cash on all orders"
- Why: Drives repeat purchases
